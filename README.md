# Spot-Inspired Robotic Arm

A 3D-printable robotic arm designed around a Raspberry Pi, PCA9685 servo driver, and hobby servos.

The arm is designed to provide multiple degrees of freedom while remaining inexpensive and easy to build with consumer 3D printers.

## Features

* 3D-printable design
* Raspberry Pi control
* PCA9685 servo control
* Rotating base
* Articulated lower and upper arm
* Wrist rotation
* Functional gripper
* Keyboard control
* Graphical control interface
* Customizable servo configuration

## Hardware

* Raspberry Pi
* PCA9685 16-channel servo driver
* Hobby servos
* 5V power supply for servos
* 3D-printed components
* Fasteners and hardware
* Wiring/connectors

## Controls

| Key               | Function            |
| ----------------- | ------------------- |
| W / S             | Arm movement        |
| Q / E             | Lower arm up/down   |
| R                 | Open gripper        |
| T                 | Close gripper       |
| [Additional keys] | Wrist/base controls |
